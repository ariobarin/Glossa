# Add Glossa in developer mode

If the plugin directory isn't available for your account or workspace, add Glossa to ChatGPT as a custom app.

1. In ChatGPT web, turn on [Developer Mode](https://help.openai.com/en/articles/12584461-developer-mode-and-mcp-apps-in-chatgpt) and create a custom MCP app.
2. Name it **Glossa** and use this MCP server URL:

```text
https://mcp.glossa.sh/mcp
```

3. Choose **OAuth**, then **Scan Tools**. Complete authorization, wait for the scan, then **Create**.

Then go back to the [quickstart](/docs/quickstart#2-install-the-cli) and install the CLI.
